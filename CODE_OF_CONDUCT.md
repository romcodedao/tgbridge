# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, and keep discussion about the work. Harassment, personal attacks and sharing other people's private information are not accepted.

**Reporting.** Contact the maintainer privately through a [private advisory](https://github.com/romcodedao/tgbridge/security/advisories/new) (it reaches only the maintainer) or by direct message to [@romcodedao](https://github.com/romcodedao) on GitHub. Reports are kept confidential. The maintainer may edit or remove contributions and block contributors who break this code, following the Covenant's enforcement guidelines.
