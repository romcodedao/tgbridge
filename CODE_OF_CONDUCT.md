# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, and keep discussion about the work. Harassment, personal attacks and sharing other people's private information are not accepted.

**Reporting.** Report privately through the repository's [Report a vulnerability](https://github.com/romcodedao/tgbridge/security/advisories/new) form, which opens a private advisory that only the maintainer sees. Use it for conduct reports too, and say in the title that it is a conduct report. Reports are kept confidential. The maintainer may edit or remove contributions and block contributors who break this code, following the Covenant's enforcement guidelines.
